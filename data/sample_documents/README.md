# Sample Educational Documents

This directory contains test documents used to validate the ingestion, chunking, and retrieval pipelines of the Multimodal Learning Agent.

## Current Files
- `sample.pdf`: A generated multi-page educational document on *Computer Systems & Network Architecture*. Contains headings, technical text, equations (BDP, Mathis formula), and a formatted table (OSI Model layers).

## Guidelines for Adding Sample Documents
1. **Permitted Content**: Add open-license or team-authored educational PDFs (e.g. lecture notes, open syllabus summaries, technical whitepapers).
2. **Copyright Protection**: Do NOT commit copyrighted textbooks or proprietary documents.
3. **Recommended Structure**: For best testing across chunking and retrieval:
   - Include multi-page documents (2 to 20 pages).
   - Include clear headings and hierarchical sections.
   - Include diverse formatting (tables, bullet points, technical terminology, mathematical expressions).
